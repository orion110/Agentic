A minimal interface for querying local language models. Fast, private, yours.

01
Install Ollama
Download and run Ollama on your machine. It handles the local model runtime.
02
Pull a model
Run ollama pull qwen2:0.5b to download a model locally. No API key needed.
03
Ask anything
Type into the terminal below. Your prompts never leave your machine.

GLM fallback (z.ai)
If Ollama can't be reached, fall back to a GLM model by z.ai — a different one per constellation
Orion → glm-4.6 · Carina → glm-4.5 · Gemini → glm-4.5-air · Agentic → glm-4.5-flash
Groq fallback
Fast hosting for real Llama/Qwen/Gemma models — overlaps Orion, Carina, and Gemini's local families
Orion → qwen-2.5-coder-32b · Carina → llama-3.3-70b-versatile · Gemini → gemma2-9b-it · Agentic → llama-3.1-8b-instant
Mistral fallback
Official Mistral API — exact model family match for Carina, and Codestral is a strong pick for Orion
Orion → codestral-latest · Carina → mistral-large-latest · Gemini → mistral-small-latest · Agentic → mistral-small-latest
Google AI fallback
Real Gemini models from Google AI Studio — a fitting fallback for the Gemini constellation specifically
All constellations → gemini-2.0-flash
OpenRouter fallback
Catch-all router behind one key — last resort in the chain if every other fallback above fails
Orion → qwen/qwen-2.5-coder-32b-instruct · Carina → mistralai/mistral-large · Gemini → google/gemma-2-9b-it · Agentic → meta-llama/llama-3.1-8b-instruct:free
