## Features
- Terminal mode with streaming responses
- Modern chat interface 
- Voice input and speech output
- File uploads
- Chat history & projects

## How to Run

```bash
1. Install and run Ollama
2. Download `Agentic.html`
3. run : ./AGENTIC.sh

curl -fsSL https://ollama.ai/install.sh | sh
ollama pull qwen2:0.5b
ollama serve

./Agentic.sh
```

## Installation

Download the latest [`agentic.flatpak`](https://github.com/orion110/Agentic/blob/main/agentic-flatpak.zip) and run:

```bash
flatpak install agentic.flatpak
```
